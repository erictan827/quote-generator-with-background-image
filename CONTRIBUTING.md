# Contributing

Thank you for helping improve Quote Image Generator.

## Before opening an issue

- Check existing issues to avoid duplicates.
- Confirm the problem still occurs in the live demo.
- Never include API keys, access tokens, private data, or copyrighted files you cannot share.

## Reporting a bug

Use the bug report template and include:

- What you expected and what happened instead.
- Exact steps to reproduce the problem.
- Browser, operating system, and device.
- Screenshots or console errors, with sensitive information removed.

## Suggesting a feature

Explain the user problem first, then describe the proposed experience. Small, focused improvements are easiest to review.

## Pull requests

1. Fork the repository and create a focused branch.
2. Keep unrelated changes out of the pull request.
3. Test the live user flow in a modern browser.
4. Update documentation when behavior changes.
5. Complete the pull request template.
