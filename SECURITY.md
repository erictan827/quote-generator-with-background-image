# Security Policy

## Supported version

This repository currently preserves a legacy static demo. Only the latest revision on the default branch is considered for security-related maintenance.

## Important credential notice

Browser applications are public by design: any API key embedded in JavaScript can be viewed and copied. Do not reuse credentials found in this repository. Before maintaining or redeploying the app, revoke exposed credentials, create replacements with the smallest possible permissions, apply provider-side domain and quota restrictions, and proxy secret-bearing requests through a secure backend.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is unavailable, contact the repository owner privately through an appropriate channel shown on their GitHub profile.

Do not disclose an unpatched vulnerability in a public issue. Include a clear description, reproduction steps, affected behavior, and suggested mitigation if known. Never send real user data or active credentials.
