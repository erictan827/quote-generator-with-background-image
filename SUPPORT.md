# Support

## Start here

- Read the usage steps and known limitations in the [README](README.md).
- Refresh the page and try again after a short wait; the app relies on third-party services that may enforce rate limits.
- Test in the latest Chrome, Edge, Firefox, or Safari.

## Ask for help

Open a [GitHub issue](https://github.com/erictan827/quote-generator-with-background-image/issues/new/choose) and include the browser, device, steps to reproduce, expected result, and actual result.

Public issues are not a secure support channel. Never post API keys, tokens, passwords, private data, or undisclosed vulnerabilities.
